# Tanya-Tanya Adit

---

### Overview
👋🏻 Welcome to Tanya-Tanya Adit, the place where you can ask me anything and i'll (try to) answer it! So, this repo is basically a question box.

Pertanyaannya bebas mulai dari teknikal, minta sharing insights, experience, opini, etc. Just submit it as an issue here.

Gua bakaln pilih pertanyaan-pertanyaan yang menarik buat dijawab.

---

### How To Ask a Question 🤨
Pengen nanya tapi bingung gimana caranya? Santuy, gampang banget kok:
1. Click the "Issues" tab. (Yang ada di atas tuh, dekat "Code")
2. Click the "New Issue" button. (Pojok kanan atas)
3. Tulis garis besar pertanyaan kalian aja dengan singkat, padat, dan jelas di bagian "Title"
4. Di bagian "Description", bisa kalian jealsin lagi atau kasih detail kalo perlu. (Context is a key!)
5. Click "Submit new issue". (Done!!)

That's it! Tinggal tunggu gue jawab. Semoga pertanyaan lo kepilih ya!
Good luck!!
